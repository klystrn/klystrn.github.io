# Reference images needed

> Built from the drafted storyboards (`docs/story/storyboards/`). Every drafted scene is covered
> here or listed under *No reference needed*; `scripts/story/build.py` warns when one isn't.
> The Storyboard Room shows each scene's references, and has a *References* page.
>
> **Privacy:** photos of you and other people, workplace images, documents and screenshots stay
> **out of this public repo**. Keep them in a private folder (e.g. a private Drive folder) and give
> each file the reference ID as its name prefix (`REF-YOU-CURRENT-01.jpg`). The asset manifest
> only ever stores the ID, never the file.
>
> **Status:** `needed` · `received` · `not needed`. Priority: **1** = blocks the first
> generation batch (hero + Present), **2** = main story, **3** = arcs.
