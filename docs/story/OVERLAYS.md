# Code overlays — how to add and edit them

Everything a reader can read or click in Story mode is a **code overlay**: text, speech, buttons
and lists drawn by the website on top of (or under) the artwork. None of it is generated by
Higgsfield, so you can change it any time without touching an image.

**You add and edit overlays in one file: [`docs/STORY-SCRIPT.md`](../STORY-SCRIPT.md).**
Each overlay is one line under its panel, starting with its content type:

```markdown
#### Panel C05-S02-P01 · Networking session
- NAR {draft}: At a networking session, coffee in hand, I meet the people I'll be learning from.
- DIA[Rahul] {draft}: So, tell me about yourself.
- DIA[Reginald] {draft}: I work hard, and I keep people in the loop.
- SKL {draft}: Communication
- PORTAL[testimonial-rahul] {draft}: Read Rahul Varma's testimonial
```

Then run `python3 scripts/story/build.py` (or ask Claude) and push. A new line shows up on the
site straight away: under the panel by default, or on the artwork once the storyboard gives it a
position.

## Content types

| Write this | It becomes | Notes |
|---|---|---|
| `NAR: text` | Narration box (ivory, red bar) | Your voice, present tense |
| `DIA[Name]: text` | Speech balloon with the speaker's name | `Name` is required — use `DIA[Reginald]` for your own speech |
| `THO: text` | Thought bubble (dashed) | Your private thoughts |
| `FAC: text` | Fact box (black, mono type) | Dates, numbers, roles |
| `SKL: Skill, Skill` | Skill chips | 1–3 skills, comma separated; use names from the portfolio's skills list where you can |
| `SFX: WORD` | Big hand-lettered sound effect | e.g. `RING`, `TICK` |
| `SUB: text` | Subtitle on a selection card | Only inside `##### Item` blocks |
| `PORTAL[arc-slug]: label` | **Button to a side story (arc)** | `arc-slug` is the arc's name from its `# Arc <slug>` heading; label in past tense |
| `MODAL[Button label]: item \| item \| item` | **Button that opens a pop-up list** | Items separated by ` \| ` (e.g. the awards list) |
| `VISUAL: text` | Nothing on screen | Describes the artwork; becomes the image's alt text |
| `NOTE: text` | Nothing on screen | A note to yourself or Claude |

Status after the type: `{draft}` (default), `{approved}` (final — only you set this), `{edit}`
(needs your attention). Lines containing `[EDIT: …]` are hidden on the site until you fill them.

## Common edits

- **Change wording:** edit the text after the colon.
- **Change who speaks:** edit the name in `DIA[...]`.
- **Turn narration into speech (or back):** change `NAR` to `DIA[Name]` (or the reverse).
- **Add a button to a side story:** add `- PORTAL[arc-slug] {draft}: What I did` to the panel.
- **Add a pop-up list:** add `- MODAL[Button label] {draft}: first | second | third`.
- **Remove an overlay:** delete its line.
- **Selection cards:** each card is a `##### Item` block with `title:`, a `SUB` line and
  optionally `skills: [A, B]` and `arc: arc-slug` (the card's button destination).

## Where an overlay appears

- **Desktop:** if the panel's storyboard has a box for that line (`cap TYPE x y width` in
  `docs/story/storyboards/`), it sits there on the artwork — it may straddle the frame edge like a
  comic. Lines without a box appear in a row under the panel. To move a caption, tell Claude where
  ("put Rahul's line top-right") or edit the `cap` numbers (percent of the frame).
- **Phones:** every frame is shown whole and all of its overlays stack underneath, in script order.
- The two views of every panel are in the Storyboard Room (Desktop / Mobile toggle).

## Easter eggs (also code)

- **Watches** — comments live in [`WATCHES.md`](WATCHES.md); where each watch sits is set in the
  storyboards (`watch X Y <id>`). The first and last sighting of each watch get a shadowy shimmer
  and a comment card on hover or tap.
- **Ducky** — one per chapter (`ducky X Y H show=…` in the storyboards). Grey and camouflaged until
  clicked, then yellow; finding all of them shows "I like Ducks!".

## What is *not* an overlay

Only the picture inside the frame is generated. The **panel frame itself** (the inked border) is
drawn in code, as are titles, the nav box, cards, charts, lists and diagrams. One exception you
asked for: the Grafana dashboard in `C05-S05` is painted into the image.

A generated list of every overlay currently in the story is in
[`OVERLAY-INDEX.md`](OVERLAY-INDEX.md).
